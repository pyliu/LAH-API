智慧控管與監控系統 (LAH) - PHP 8.5 雙軌運行與 Apache 轉址部署指南

提供在地政事務所現有 Apache 2.4 (PHP 7.4 mod_php7) 伺服器中，部署 PHP 8.5 FastCGI (lah-api-v85) 監聽 Port 8085 與反向代理完整轉址配置範例。

一、系統架構與拓撲分流原則

為達成線上業務零中斷、前後端平滑過渡，本架構維持單一 Apache 2.4 入口（Port 80），並依 URL 進行動態代理分流：

客戶端層
LAH-FE 網頁前端
lah-messenger 即時通
Apache 2.4 Web 閘道 (Port 80)
C:\AppServ\Apache24
mod_php7 + mod_proxy_fcgi
線上舊軌 (PHP 7.4 TS)
路徑：/api/*.php
目錄：C:\AppServ\www
新軌 FastCGI (Port 8085)
路徑：/LAH-API/v1/*.php
守護：PM2 (16 Workers)
全域邊界標準定義：
• PHP 8.5 根目錄：C:\AppServ\php85（採用 64 位元 Non-Thread Safe / NTS 版本）
• 新軌 API 專案：C:\AppServ\LAH-API（核心端點位於 v1/ 子目錄）
• FastCGI 監聽埠：127.0.0.1:8085（由 PM2 守護單一父進程，底層自動衍生 16 個子進程）

二、部署途徑 A：PowerShell 一鍵自動化腳本

LAH-API 專案內建全自動安裝工具 install_php85.ps1，能自動備份設定檔、解壓套件、修改 Apache 與啟動 PM2。

1. 線上模式（伺服器具備外網連線）

以「系統管理員身分」開啟 PowerShell 終端機執行：

# 進入 LAH-API 專案目錄並放行執行原則
cd C:\AppServ\LAH-API
Set-ExecutionPolicy Bypass -Scope Process -Force

# 執行一鍵安裝（並啟用智慧無感 Rewrite 分流）
.\install_php85.ps1 -EnableSmartRewrite

2. 離線模式（內網封閉環境）

在有網路環境預先下載：

  • PHP 8.5.12 NTS x64 壓縮包：php-8.5.12-nts-Win32-vs17-x64.zip
  • VC++ 2015-2022 執行期套件：vc_redist.x64.exe

複製至伺服器 D:\OfflinePkg\ 後執行：

cd C:\AppServ\LAH-API
Set-ExecutionPolicy Bypass -Scope Process -Force
.\install_php85.ps1 -PhpZipPath "D:\OfflinePkg\php-8.5.12-nts-Win32-vs17-x64.zip" -EnableSmartRewrite

三、部署途徑 B：手動逐步配置 SOP

步驟 1：安裝 Visual C++ 2015-2022 (VS17) 執行期庫

PHP 8.5 依賴 Visual Studio 2022 執行期元件，請於伺服器執行靜默安裝：

vc_redist.x64.exe /install /quiet /norestart

步驟 2：解壓縮 PHP 8.5 至 C:\AppServ\php85

確認目錄結構完整包含 php.exe、php-cgi.exe 與 ext\ 子目錄：

C:\AppServ\php85\
├── php.exe
├── php-cgi.exe         <-- FastCGI 核心進程
├── php8.dll
├── php.ini-production
└── ext\                <-- 擴充模組庫 (php_curl.dll, php_sqlite3.dll...)

步驟 3：配置 C:\AppServ\php85\php.ini

複製 php.ini-production 為 php.ini，並啟用下列模組：

; 1. 啟用擴充模組相對路徑 (取消分號 ;)
extension_dir = "ext"

; 2. 啟用核心業務相依擴充套件
extension=curl
extension=gd
extension=intl
extension=mbstring
extension=openssl
extension=pdo_sqlite
extension=sqlite3
extension=odbc

; 3. 系統資源與執行期限制
memory_limit = 512M
max_execution_time = 300
post_max_size = 100M
upload_max_filesize = 100M

; 4. 設定本地時區
date.timezone = Asia/Taipei

在命令提示字元輸入 C:\AppServ\php85\php.exe -m 檢視擴充模組清單，確認模組已正確載入。

步驟 4：修改 Apache 設定檔 (C:\AppServ\Apache24\conf\httpd.conf)

操作前提醒： 請先將 httpd.conf 複製為 httpd.conf.bak 進行備份。

4.1 確認啟用 4 大核心模組（取消前方 #）：

LoadModule proxy_module modules/mod_proxy.so
LoadModule proxy_fcgi_module modules/mod_proxy_fcgi.so
LoadModule headers_module modules/mod_headers.so
LoadModule rewrite_module modules/mod_rewrite.so

4.2 於 httpd.conf 最末端追加 LAH-API 轉發區塊：

# =====================================================================
# LAH-API (PHP 8.5 FastCGI via PM2 on 127.0.0.1:8085)
# =====================================================================
# 1. 優先定義相容 Alias：將舊呼叫端之 /api/ 映射至實體 /v1/ 目錄
Alias /LAH-API/api "C:/AppServ/LAH-API/v1"
Alias /lah-api/api "C:/AppServ/LAH-API/v1"

# 2. 服務根目錄映射
Alias /LAH-API "C:/AppServ/LAH-API"
Alias /lah-api "C:/AppServ/LAH-API"

<Directory "C:/AppServ/LAH-API">
    Header set Access-Control-Allow-Origin "*"
    Options Indexes FollowSymLinks
    AllowOverride None
    Require all granted

    <FilesMatch "\.php$">
        # 安全防護：確認檔案存在才轉發，並剝除 Proxy 前綴以利 Windows 解析
        <If "-f %{REQUEST_FILENAME}">
            SetHandler "proxy:fcgi://127.0.0.1:8085/"
            ProxyFCGISetEnvIf "reqenv('SCRIPT_FILENAME') =~ m#^proxy:fcgi://127\.0\.0\.1:8085/(.*)$#" SCRIPT_FILENAME "$1"
        </If>
    </FilesMatch>
</Directory>

# 設定 FastCGI 連線池 (16 併發、300 秒逾時)
<Proxy "fcgi://127.0.0.1:8085/" enablereuse=on max=16>
    ProxySet timeout=300
</Proxy>

4.3 [進階選用] 舊路徑 /api/* 智慧無感轉發 (Smart Rewrite)：

在原本的 <Directory "C:/AppServ/www"> 區塊內部加上以下條件重寫規則：

    # -------------------------------------------------------------
    # LAH-API 舊路徑漸進智慧分流：
    # 當請求 /api/*.php 時，若新軌 v1/ 存在該檔案，自動由 PHP 8.5 執行
    # 若新軌尚未移植，則無縫由原本的 PHP 7 mod_php7 執行！
    # -------------------------------------------------------------
    <IfModule mod_rewrite.c>
        RewriteEngine On
        RewriteCond "C:/AppServ/LAH-API/v1/$1" -f
        RewriteRule ^api/(.*\.php)$ "fcgi://127.0.0.1:8085/C:/AppServ/LAH-API/v1/$1" [P,L]
    </IfModule>

4.4 測試 Apache 語法：

C:\AppServ\Apache24\bin\httpd.exe -t

確認輸出為 Syntax OK。

步驟 5：配置 PM2 守護進程 (ecosystem.config.js)

於 C:\AppServ\LAH-API\ecosystem.config.js 配置守護參數：

module.exports = {
  apps: [
    {
      name: "lah-api-v85",
      script: "C:\\AppServ\\php85\\php-cgi.exe",
      args: "-b 127.0.0.1:8085 -c C:\\AppServ\\php85\\php.ini",
      cwd: __dirname,
      interpreter: "none",          // 告知 PM2 為原生 EXE
      exec_mode: "fork",            // 原生 EXE 必須使用 fork 模式避免埠衝突
      instances: 1,                 // 父進程 1 個，子進程由 PHP_FCGI_CHILDREN 接管
      autorestart: true,
      watch: false,
      max_memory_restart: "1G",
      env: {
        PATH: "C:\\Tools\\instantclient_11_2;C:\\AppServ\\php85;" + process.env.PATH,
        NLS_LANG: "American_America.US7ASCII",
        PHP_FCGI_CHILDREN: "16",     // 自動在 Windows 底層衍生 16 個 worker
        PHP_FCGI_MAX_REQUESTS: "10000" // 滿萬次請求平滑重啟，防止記憶體洩漏
      }
    }
  ]
};

啟動 PM2 進程並儲存自啟動清單：

$env:PATH = "C:\AppServ\node;" + $env:PATH
cd C:\AppServ\LAH-API
pm2 start ecosystem.config.js
pm2 save

步驟 6：重啟 Apache 與驗收檢查

# 重啟服務
Restart-Service -Name "Apache2.4" -Force

# 確認 Port 8085 正在監聽中
Get-NetTCPConnection -LocalPort 8085 -State Listen

四、驗收檢查清單 (Acceptance Matrix)

驗收端點 預期 HTTP 狀態 驗收內容與驗證重點
http://127.0.0.1/LAH-API/ver.php 200 OK 回傳 JSON，確認 php_version 為 8.5.x，sapi 為 cgi-fcgi。
http://127.0.0.1/LAH-API/v1/system_json_api.php 200 OK 新版標準 API 轉發成功，正確返回業務 JSON 資料。
http://127.0.0.1/LAH-API/api/system_json_api.php 200 OK 新版相容 API 轉發成功，舊呼叫端無縫相容。
http://127.0.0.1/ver.php 200 OK 回傳 PHP 7.4.x 頁面，確認線上原有 mod_php7 舊軌零干擾。

五、故障排查指南 (Troubleshooting)

  • 出現 503 Service Unavailable：代表 Apache 無法連線至 127.0.0.1:8085。請執行 pm2 status 確認 lah-api-v85 為 online 狀態，或透過 pm2 logs lah-api-v85 檢查是否有缺少 VC++ 執行庫或 DLL 載入失敗問題。
  • 出現 404 Not Found：確認 httpd.conf 中 Alias 是否正確指向 C:/AppServ/LAH-API 與 v1/ 子目錄，且路徑請統一使用正斜線 /。
  • Apache 無法啟動 (Syntax Error)：請檢查 mod_proxy.so 是否在 mod_proxy_fcgi.so 之前載入。
